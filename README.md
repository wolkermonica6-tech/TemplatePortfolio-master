RICHARD CAR PARTS — starter website

FILES
- index.html: page structure
- style.css: black-and-gold responsive styling
- script.js: sample products, search/filter, cart, seller listing form and WhatsApp enquiries

HOW TO OPEN
1. Download and extract the ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. No build step is needed.

IMPORTANT
This is a front-end starter/demo. Products and cart are stored in the browser's localStorage on that device only. Seller submissions are not published to a shared online catalogue. There is no real payment processing, user authentication, server database, or admin login yet. For a live marketplace, connect a secure backend/database and add seller verification, moderation, privacy protections and a trusted payment provider.
